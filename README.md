# Трекер расходов в Telegram

Заявка для CodeCup.tech: бот записывает трату одним сообщением, а web-панель показывает личные расходы, итоги и графики. У каждого запроса есть проверка владельца: пользователь может читать, менять и удалять только собственные записи.

## Что готово

- Telegram-бот: `45 такси`, `120 обед #Еда`, `/today`, `/week`, `/month`.
- FastAPI + PostgreSQL, Telegram Login с проверкой подписи, CRUD трат.
- Итоги сегодня/неделя/месяц; диаграммы по дням и категориям текущего месяца; адаптивная панель.
- CSV-выгрузка, помесячные лимиты категорий и rule-based автокатегоризация.
- Docker Compose, healthcheck, `.env.example`; секреты исключены из Git.

## Локальный запуск

1. Скопируйте `.env.example` в `.env`, замените **все** значения `replace-with-…`; `POSTGRES_PASSWORD`, `APP_SECRET` и `BOT_API_TOKEN` должны быть длинными случайными строками.
2. Создайте бота в BotFather, внесите его токен и username. В BotFather укажите домен web-панели для Telegram Login.
3. Запустите `docker compose up --build`.
4. Откройте `http://localhost:3000`. API health: `http://localhost:8000/health`.

Для публикации передайте сайту HTTPS-домен, задайте `WEB_ORIGIN` этим доменом и используйте managed PostgreSQL с резервным копированием. Не открывайте `/api/bot/*` наружу через публичный ingress: бот и API должны быть в одной приватной сети.

## Проверка перед конкурсом

- Войти двумя Telegram-аккаунтами; убедиться, что записи первого не видны второму.
- Создать, отредактировать и удалить трату в панели; создать трату ботом.
- Проверить `/today`, `/week`, `/month`, CSV, мобильный экран и диаграммы.
- Записать видео 2–3 минуты: бот → панель → CRUD → отчёты → изоляция пользователей.

## Ограничения текущей версии

Лимиты категорий хранятся и настраиваются через API (`PUT /api/limits`); уведомления о превышении — следующий небольшой шаг. Нужны также миграции Alembic перед первой production-публикацией вместо `create_all` на старте.
